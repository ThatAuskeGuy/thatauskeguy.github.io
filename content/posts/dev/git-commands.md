## For the struggling solo developer

I have been coding for a few years now, and I have always wanted to use git. I have always loved the idea of it, but I have never been able to figure it out. It has always felt like some kind of dark magic. Thankfully, with AI, I have made some progress in figuring out how to use it, but I am very much a paper and pen sort of person. I have looked online for git cheatsheets, but they have always seemed too complicated.

The part of git I want to move to now is branching. As I'm developing some websites, I know I will need to make some edits and add new features, but I don't want to risk accidentally pushing broken code to my production. Branching helps with this. I can branch off my main line, make my changes, test them, and then push them to main when I'm ready. I love that about git.

So anyways, I asked ChatGPT to create a git cheatsheet for the solo developer, which has been included here. Yes I've printed it out. It just works better for me that way. If you've stumbled upon this post for some reason, I hope you will find some usefulness from this cheatsheet like I have.

Ramblings over, here's the cheatsheet.
